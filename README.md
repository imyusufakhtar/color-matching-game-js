# Color Matching Game

## Overview

The **Color Matching Game** is an engaging and interactive memory game built using **HTML**, **CSS**, and **JavaScript**. Players are tasked with matching pairs of colored tiles, which are shuffled randomly each time, ensuring a unique and challenging experience with every game session. The game provides an opportunity to enhance memory, concentration, and pattern recognition in a fun and interactive environment.

## Features

- **Randomized Tiles**: Tiles are shuffled every time the game is played, ensuring a fresh challenge.
- **Timer**: Players have a limited amount of time to find all matching pairs.
- **Score System**: Track and display your score based on the number of matches found.
- **Responsive Design**: The game is optimized for various screen sizes and devices.
- **User-Friendly Interface**: Clean and simple layout with intuitive controls.

## Technologies Used

- **HTML5**: For structuring the webpage content.
- **CSS3**: For styling the game elements and making the game visually appealing.
- **JavaScript**: For implementing the game logic, tile shuffling, and interactivity.

## How to Play

1. **Start the Game**: Click the "Start" button to begin.
2. **Reveal Tiles**: Click on a tile to reveal its color.
3. **Match Tiles**: Click on another tile to reveal its color.
4. **Check for Match**: If the two tiles match, they will remain visible. If not, they will be hidden again.
5. **Goal**: Continue finding matching pairs until all tiles are matched.
6. **Timer**: The timer runs throughout the game, challenging you to match all tiles before time runs out.

## Benefits of Playing

- **Improved Memory**: Helps strengthen short-term memory by encouraging players to remember tile locations.
- **Enhanced Concentration**: Challenges players to stay focused to find matching pairs.
- **Increased Cognitive Agility**: Stimulates brain function by requiring quick thinking and pattern recognition.
- **Mental Fitness**: Provides a fun way to keep the brain active and healthy.

## Installation

To run this game locally, follow these steps:

### Prerequisites

- A web browser (e.g., Chrome, Firefox, Edge).

### Setup

1. Clone this repository to your local machine:

    ```bash
    git clone https://github.com/imyusufakhtar/color-matching-game-js.git
    ```

2. Navigate to the project directory:

    ```bash
    cd color-matching-game-js
    ```

3. Open the `index.html` file in your browser to start playing the game.

    ```bash
    open index.html
    ```
